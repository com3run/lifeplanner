## Operating rhythm

- **Monday 10am (Baku time)**: 30-min weekly review. Open `01-uk-launch-campaign.md` §7 (Weekly review template). Fill in, decide on changes, move on.
- **End of month**: month retro and update to `00-strategy.md` if north-star metrics warrant a direction change.
- **Before spending $1**: confirm the ad set matches what's specified in `01-uk-launch-campaign.md`. If it doesn't, update this doc FIRST, then spend.
